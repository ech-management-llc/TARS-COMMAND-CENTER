TEXT-TARS LANE — STANDING REQUIREMENT (Rule 27)
Texting TARS is a first-class input lane on everything in Foundation Layer, and TARS always responds. Every new tile/feature spec must define its Text-TARS lane from day one: what an allow-listed team member can do here by SMS to the TARS line, which employee handles it, and what TARS replies. Entries that arrive this way carry the source Text TARS · <name> (field). Unknown numbers NEVER execute commands — they file to the Inbox as correspondence.
